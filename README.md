# Carona Solidária · Recife

**Este endereço agora redireciona para o site único da Carona Solidária:** <https://caronasolidaria.github.io/?cidade=recife>

Quem abre <https://caronasolidaria-recife.github.io/> (ou qualquer página dele) é levado para lá, já em Recife. O cadastro de motorista guardado no celular vai junto, sem precisar se cadastrar de novo.

O código do site e as instruções ficam em <https://github.com/caronasolidaria/caronasolidaria.github.io>. Este repositório guarda só o redirecionamento (`index.html` e `404.html`) e o `apps-script/Code.gs` usado na planilha de Recife (`NOME_CIDADE = 'Recife'`).
